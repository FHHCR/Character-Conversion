## 项目概述

一个 Windows 可视化文件字符集转换工具，支持批量转换常见编码（GBK、UTF-8、GB2312、BIG5 等）。

## 后续可扩展功能

- 支持拖拽文件到窗口
- 支持更多编码（如 KOI8-R、CP1251 等）
- 支持文件内容预览
- 支持转换后自动打开目录
- 支持命令行模式（批量转换）

## 注意事项

1. 本程序在 Windows 环境下运行需要 Python 3.10+（Windows 版 Python 自带 tkinter）
2. 转换大文件（>500MB）可能会有性能问题
3. 默认不覆盖原文件，请谨慎使用"覆盖原文件"选项
