# 文件字符集转换工具

一个 Windows 可视化文件字符集转换工具，支持批量转换常见编码（GBK、UTF-8、GB2312、BIG5 等）。

## 功能特性

- ✅ 支持多文件/文件夹选择
- ✅ 支持常见编码转换（GBK、UTF-8、GB2312、BIG5 等 12 种编码）
- ✅ 自动检测文件编码
- ✅ 批量转换，实时显示进度
- ✅ 不覆盖原文件，安全可靠（默认保存到输出目录）
- ✅ 结果日志记录，支持查看转换详情
- ✅ 支持中/日/韩/emoji 等特殊字符
- ✅ 轻量级，零第三方运行时依赖

## 安装与部署

### 环境要求

- **Windows** 7 或更高版本（推荐 Windows 10/11）
- **Python 3.10** 或更高版本
- Python 自带 Tkinter（Windows 版 Python 默认包含）

### 运行源码

```bash
# 1. 克隆或下载项目到本地
# 2. 进入项目目录
cd Character-Conversion

# 3. 直接运行（无需安装依赖）
python main.py
```

### 打包为 exe（可选）

如果你想在未安装 Python 的电脑上运行：

```bash
# 1. 安装 PyInstaller
pip install pyinstaller

# 2. 打包为单文件 exe
pyinstaller --onefile --windowed --name=字符转换工具 main.py

# 3. 打包后的 exe 位于 dist/ 目录
```

## 使用方法

### 快速开始

1. **启动程序**：双击 `main.py` 或运行 `python main.py`
2. **添加文件**：点击"添加文件..."选择要转换的文件，或点击"添加文件夹..."选择整个文件夹
3. **选择编码**：
   - 勾选"自动检测源编码"可自动识别文件编码
   - 或手动选择源编码（如 GBK）和目标编码（如 UTF-8）
4. **选择输出目录**：点击"浏览..."选择转换后文件的保存位置
5. **开始转换**：点击"开始转换"按钮，查看进度和日志
6. **查看结果**：转换完成后，日志区域会显示每个文件的转换结果

### 注意事项

- **默认不覆盖原文件**：转换后的文件保存到输出目录，文件名格式为 `原文件名_目标编码.扩展名`（如 `test_utf-8.txt`）
- **覆盖原文件**：如果勾选"覆盖原文件"，转换结果会直接写入原文件（请谨慎使用，建议先备份）
- **大文件**：程序将整个文件读入内存，对于超大文件（>500MB）可能会有性能问题
- **二进制文件**：程序主要针对文本文件，二进制文件（图片、视频等）可能无法正确转换
- **特殊字符**：某些目标编码无法表示源文件中的特殊字符（如 GBK 无法表示 emoji ✅、🎉），此时可选择错误处理策略：
  - **严格模式（报错）**：默认，遇到无法编码的字符时报错
  - **替换字符（?）**：用 `?` 替换无法编码的字符
  - **忽略字符**：跳过无法编码的字符
  - **XML实体引用**：用 `&#x2705;` 形式保留字符信息

## 支持的编码

| 编码名称 | 编码标识 | 说明 |
|----------|----------|------|
| UTF-8 | utf-8 | 标准 UTF-8（最常用） |
| UTF-8 BOM | utf-8-sig | 带 BOM 的 UTF-8（Windows 兼容） |
| UTF-16 LE | utf-16-le | UTF-16 小端 |
| UTF-16 BE | utf-16-be | UTF-16 大端 |
| GBK | gbk | 简体中文（Windows 默认） |
| GB2312 | gb2312 | 简体中文（旧标准） |
| GB18030 | gb18030 | 简体中文（新标准） |
| BIG5 | big5 | 繁体中文 |
| Shift-JIS | shift_jis | 日文 |
| EUC-KR | euc_kr | 韩文 |
| ASCII | ascii | ASCII |
| Latin-1 | latin-1 | Latin-1 |

## 常见问题

### Q1: 程序报错 "No module named 'tkinter'"
**原因**：Python 安装未包含 Tkinter。
**解决**：重新安装 Python，勾选 "tcl/tk and IDLE" 选项。

### Q2: 转换后文件乱码
**原因**：源编码选择错误，或自动检测失败。
**解决**：手动选择正确的源编码后重试。

### Q3: 转换中文内容到 ASCII 失败
**原因**：ASCII 编码无法表示中文字符。
**解决**：选择 UTF-8 或 GBK 作为目标编码。
